# Pitwall2027

App Android (APK) di PitComm e relativi strumenti.

- Il server e la web app restano nel repository `pitwallnew` (Render).
- Qui: l'involucro Android che apre la web app, con schermo sempre acceso, notifiche e allarmi a schermo spento, e (poi) le zone GPS box / rifornimento.
- Gli iPhone usano la web app di Render installata nella schermata Home.
